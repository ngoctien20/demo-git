## Private schema proposal — DO NOT APPLY TO HOSTED
Use a **private non-exposed schema** with least-privilege DB roles, migration after backup and approval. Do not reuse the V19.8.12 local public SECURITY DEFINER functions as hosted implementations.

**trusted_installations**:
`installation_id` UUID PK; `provider` enum ZALO_BOT; `bot_id_digest` salted keyed digest (unique per provider); `callback_ref` opaque trusted HTTPS callback pointer; `credential_binding_ref` opaque internal pointer; `credential_epoch` positive int; `tenant_id`, `store_id`, `owner_user_id` UUID FKs to canonical Store and active membership (not merely tenant member); `version` positive int; `state` PENDING|ATTESTED|READONLY_APPROVED|REVOKED; `verified_at`, `revoked_at`; unique active Bot mapping using a partial unique index. **Never** store raw Bot token, shared secret, callback URL, or owner JWT.

**provider_attestations**:
`attestation_id`, `installation_id`, `installation_version`, `observed_at`, `expires_at`, `get_me_match`, `get_webhook_match`, `header_secret_binding_reviewed`, `credential_epoch`, `operator_ref`, `evidence_digest`, `signature_ref`. The signed provenance must be attested by a trusted reviewer in a protected system; no chat or screenshots as sole authority. Expired, stale, revoked, mismatched version or duplicated evidence denies admission.

**owner_consent_challenges**:
`challenge_id`, `installation_id`, `owner_user_id`, `tenant_id`, `store_id`, `installation_version`, exact `scope=readonly_catalog_qa_only`, `nonce_sha256`, `issued_at`, `expires_at` <=5 minutes, `consumed_at`. Nonce is generated by the server (>=256 bits), hash only stored. Transaction locks challenge and grant; replay and concurrent consumption fail. Privileged mutations callable only via vetted server paths; revoke bound grants when installation/version/store membership changes.

**owner_consent_grants**:
`installation_id`, `owner_user_id`, `tenant_id`, `store_id`, `installation_version`, `scope`, `consented_at`, `revoked_at`, proof reference. Enforce live JWT validation, current *store* owner membership, and current exact version on **every catalog read**, not just consent time. An owner can authorize only their own Store, with no read/write grant for other stores.

## Hosted admission decision
Policy `hosted-admission.mjs` is **pure source-only QA**: it is not itself proof of authenticity. The booleans are only valid when assembled and signed by an independent trusted hosted verifier; NEVER accept the evidence object from a client, Messenger/Zalo payload or AI Agent. The policy always returns `canSend=false`, `canWriteOrders=false`; even successful admission only authorizes protected QA catalog read.
