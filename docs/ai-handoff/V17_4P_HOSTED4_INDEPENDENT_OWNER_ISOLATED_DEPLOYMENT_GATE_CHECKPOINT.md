### B. Fail-closed, dual-signature authorization contract (implemented as source only)

`qa/v174p-private-hosted/hosted4-independent-owner-gate.mjs` implements a **pure read-only** evaluator. The signed envelope must cover the same canonical JSON across two independent Ed25519 signatures:

1. **Owner** proves scoped consent to QA-only deployment, with **separately provisioned public trust anchor**;
2. **Security reviewer** independently confirms scope, risk, plan and different signing key;
3. exact Cloudflare account ID, V17.4P Worker/class, authenticated code SHA, 7 named new QA resources, explicit private HTTPS origin and up to 3 exact operator emails (no broad domain/wildcards);
4. phase **`INACTIVE_UPLOAD_ONLY`**, no public route, no provider sends, no LLM calls, no real customer/Commerce, max **96 HTTP QA requests**, independent cost approval in USD;
5. signed envelope expires within **one hour**; validates signature and fields, and rejects stale snapshot older than **10 minutes**;
6. independently attested Cloudflare read-only inventory must show **all known V17.5E.2/A resources present and untouched**, no V17.4P worker/DO/Access collisions, no shared-bound secrets/routing/data;
7. evidence of operator access review, rollback readiness, no-public-route preflight, cost and shared-account spend-risk review.

**IMPORTANT:** Public verification keys can be generated by anyone. A valid Ed25519 signature only proves possession of the paired private key, **not that it belongs to the real owner**. A human operator must register the authorized owner/reviewer identities and their trust anchors in a separately controlled system. The sample test keys are ephemeral and not valid authorization; the sample JSON deliberately includes **no signatures, no account secrets, no owner identity**. The gate always returns `deploy_authorized:false`, `enable_public_route_authorized:false`, `run_real_browser_authorized:false`, `verified_owner_authority:false`, even if test signatures mathematically verify; passing it is **not** permission to mutate infrastructure.
