## 4. Real versus synthetic distinctions
- REAL: HTTPS handshake and HTTP exchange between a Chromium browser and an ephemeral loopback Node service in CI; HMAC was computed/verified; browser UI actually operated; server-side tests checked status and data.
- SYNTHETIC: merchant, Store A/B, installation, owner evidence, catalog, signing test scope, fake test message, Domain; the user is NOT real signed-in customer; HTTPS certificate is self-signed only for local QA.
- NOT VERIFIED: actual merchant domain control, user/customer identity, Store membership and hosted JWT-RLS, public staging issuer ingress, production trusted TLS, distributed replay, real AI model conversation and real vendor notifications.
- Browser Origin alone is NOT an identity proof. Signed anonymous Website chat sessions do not authorize cross-channel order lookup or Commerce orders.
- A realistic fake owner attestation HMAC cannot replace actual DNS/HTTP domain challenge and an Owner/Store-mapping authorization source.
