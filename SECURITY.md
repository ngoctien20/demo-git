# TIEN404 AI Security Policy (DRAFT)

**Do not disclose vulnerabilities, access tokens, personal data, merchant data or exploit details in public issues or pull requests.**

Contact the repository owner through an established private channel. Use GitHub's Private Vulnerability Reporting only if it has been enabled for this repository.

Production testing, security scanning against live systems, active exploitation and access to third-party merchant accounts are not authorized. Security reproductions need explicit scope and disposable/synthetic staging environments.

Response times, coordinated disclosure rules and any reward/bounty program remain to be approved.
